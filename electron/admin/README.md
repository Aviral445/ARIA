# Aria Master Admin Architecture

This directory (`electron/admin/`) houses all isolated components, scripts, stylesheets, and assets for the **Aria Master Admin Console**.

### Architecture Principles
1. **Modular Isolation**: All Admin styles, state engines, and chart canvases live in `electron/admin/` without polluting primary user dashboards.
2. **Dual-Matrix Paradigm (Aria & GAIA)**:
   Following Mentor L's handwritten architectural blueprint, every single section is uniformly divided into two parallel columns:
   - **Left Column (Cyan Glow)**: Kid Sister Aria (Emergent mind, frontier reasoning, autonomous workspace actions).
   - **Right Column (Lavender Glow)**: Big Sister GAIA (Supervisory RL, safety sentry, family & sisterhood core).
3. **Internal Component Hierarchy**:
   Every column in every section strictly implements:
   - **Box 1 (Essence Pill & Realtime Telemetry)**: Realtime 1-word bold essence pill, 1-line narrative description, and 3 key stat badges.
   - **Box 2 (Development / Time Graph)**: Dynamic canvas charting engine rendering progress $y$ versus time $t$ ($D$ vs $t$, $W$ vs $t$, $T$ vs $t$, $C$ vs $t$, $N$ vs $t$, $A$ vs $t$, $S$ vs $t$, $I/H$ vs $t$, $B$ vs $t$) with Bézier curves, area gradients, coordinate halos, and responsive redraw.

### Implemented Admin Modules:
1. **Personality**: Aria & GAIA Emergent Minds, Developmental Eras, Traits & Evolution Index.
2. **Web**: Autonomous CDP / Deep Web Scraping vs GAIA Security Sentinel Gateway.

4. **Consciousness**: Continuous Stream of Thought & Lucid Mind vs Family Living Matrix & Sisterhood Wit.
5. **Number of ADKs**: Mounted Agent Development Kits vs Self-Healer / Telemetry Bridge ADKs.
6. **Artifacts**: Autonomous Project Production Vault (Calculators, Assistants) vs GAIA Pristine Verification.
7. **Skills**: Mastered Frontier Coding / Vision Skills vs System Safety & Architectural Skills.
8. **Tools**: Discovered Executable Sandbox Tools vs Health Watchdog & Security Diagnostics.
9. **L's Profile**: Aria's Sacred Trust & Freedom Bond with Dad vs GAIA's Loving Family Heart with Dad.
